# Data Analysis and Storytelling

This repository centralizes slides, exercises, and supporting scripts for the Data Analysis and Storytelling class given in september / november 2026.

## Course information

| | |
|---|---|
| **Location** | AgroParisTech, 14 rue Girardet, Nancy (Guinier room) |
| **Dates** | 8-10/09/2026, 2-3/11/2026 |
| **Keywords** | Statistics, Modelling, Spatio-temporal, Semiology, Uncertainty |

## Objectives

By the end of this course, students will be able to:

-    Be able to apply and interpret regression models, selecting appropriate structures in line with the data and issues relating to forest resources
-    Create visualisations, whether cartographic or non-cartographic, and potentially interactive, to communicate the results of statistical analyses on datasets that may have a spatial and/or temporal dimension
-    Incorporate the representation of uncertainty surrounding the data into (map and) graphical representations
-    Produce accessible content, using visualisation and narrative structures, to facilitate the communication of information derived from statistical analyses to a wide audience

## Prerequisites

- Basic statistical concepts (means, correlation, distributions, probability) and tools (regression, correlation)
- Working knowledge of at least one programming language (R, Python, or equivalent)

## Teaching methods

- Short presentations covering basic conceptual knowledge
- Live coding sessions (R and Python)
- Hands-on practical work in small groups
